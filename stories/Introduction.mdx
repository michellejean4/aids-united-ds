## How to use this

This Storybook is a parallel reference to the Figma file. Designers work in Figma; developers
work here. Both reference the same `tokens.json` source of truth.

- **Foundations** — colors, type, spacing, radii, shadows
- **Components** — buttons, inputs, cards
- **Patterns** — header, footer, hero, stats, donate, newsletter
- **Accessibility** — contrast pairs and checklist

Every component story shows the HTML structure and the CSS classes that map directly to
Webflow combo classes.

## Hard rules (non-negotiable)

<div className="rule">No pink. Ever. Not as tint, not as gradient.</div>
<div className="rule">True brand red #C42032 — NOT the orange-red on the current site.</div>
<div className="rule">No homemade-looking icons. Use a real icon set.</div>
<div className="rule">8px button radius. 16px card radius. Stay consistent.</div>
<div className="rule">No sticky donate button — header donate link is enough.</div>
<div className="rule">Webflow Localization handles EN/ES — don't bake English into image assets.</div>
